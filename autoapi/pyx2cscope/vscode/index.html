pyx2cscope.vscode

Create a VS Code task that starts pyX2Cscope for an MPLAB VS Code project.

The MPLAB extension for VS Code stores the project in .vscode/<project>.mplab.json. Each build configuration in that file has an imagePath with the ELF file it generates, e.g. ./out/my_project/default.elf. write_vscode_tasks() adds a “Run pyX2Cscope” task for every configuration to .vscode/tasks.json, so pyX2Cscope can be started from Terminal > Run Task with the right ELF file and connection settings.

Typical usage from the command line:

pyX2Cscope --vscode-task path/to/my_project

pyx2cscope.vscode.write_vscode_tasks(project_dir: str | pathlib.Path = '.', gui_args: list | None = None, executable: str | None = None, frozen: bool | None = None) → tuple[pathlib.Path, list[dict]][source]

Add the “Run pyX2Cscope” tasks to .vscode/tasks.json of an MPLAB VS Code project.

Existing tasks are kept; tasks with the same label are replaced. If the existing file contains comments, they cannot be kept and the original file is saved as tasks.json.bak.

Args:

project_dir (str | Path): The VS Code project folder. Defaults to the current folder. gui_args (list, optional): pyX2Cscope arguments for the task. Defaults to ["-p", "AUTO"]. executable (str, optional): Program that starts pyX2Cscope. Defaults to the running one. frozen (bool, optional): True if executable is the standalone executable.

Returns:

tuple[Path, list[dict]]: The tasks.json file and the tasks that were written.

Raises:

VSCodeTaskError: If the project is not an MPLAB VS Code project or tasks.json cannot be read.
